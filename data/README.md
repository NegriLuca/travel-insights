# Data

## `raw/`

Committed scraped catalogues (May 2024 snapshot):

| File | Rows | Operator |
|---|---:|---|
| `df_viaggi_weroad.pkl` | 531 | WeRoad |
| `df_viaggi_sivola.pkl` | 91 | SiVola |
| `df_viaggi_viaggiavventure.pkl` | 1,345 | ViaggiAvventure |
| `df_viaggi_fourseasons.pkl` | 84 | FourSeasons |
| `madeira.csv` | 11 | WeRoad / Madeira subset used in experiments |

Each pickle is a `pandas.DataFrame` with the columns:

```
Country, Nome_Viaggio, Link, Descrizione Viaggio, Mood Viaggio, Itinerario, Sottotitolo_Viaggio, PDF_Link
```

`Country`, `Mood Viaggio` and `Itinerario` are intentionally messy: lists, dicts serialised as
strings, marketing labels and macro-regions. That mess is the point of `canonical.py`.

## `processed/`

`travel_insights.json` is generated by `scripts/build_data.py`. It is committed so the dashboard
can be rebuilt without rerunning the scrapers. Do not edit it by hand.

## Not committed

Two public airport-reference CSVs used during the flight experiments are deliberately excluded
because they are large and easy to obtain:

- `airport-codes.csv` — OurAirports data (https://ourairports.com/data/)
- `flat-ui__data-*.csv` — airport dataset with the same OurAirports schema

Drop them into `data/raw/` if you want to rerun the flight notebooks.
